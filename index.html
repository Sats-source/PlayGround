How Forge3D works

  1. Drop in any image. PNG, JPG, WebP — it never leaves your device.
  2. Depth is estimated on-device. A Depth-Anything AI model runs locally via WebAssembly (downloaded once, cached). No network image upload, no credits, no limits. If the AI model can't load, a built-in shape-from-shading fallback kicks in.
  3. A dense high-poly mesh is forged. Up to ~300k triangles with sculpted displacement, baked normal maps, roughness variation and cavity AO — the same ingredients that make UE5 assets look rich.
  4. Cinematic UE5-style lighting. Image-based lighting, soft shadows, ACES filmic tone mapping and optional bloom — all real-time WebGL.
  5. Export & reuse. Download GLB (for web / Blender / Unity / Unreal), STL (for 3D printing) or PNG turntable shots.

Honest note: a single photo becomes a premium 2.5D solid (bas-relief statue). It looks fully 3D from the front hemisphere and spins nicely on a turntable — true unseen-backside hallucination isn't possible from one photo.
